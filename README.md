# ScheduleWidget Notes (Android)

노트 필기·문서 가져오기, 달력·할 일, 수업 녹음·받아쓰기, 음악, 캐릭터를 한 앱에서 쓰는 Android 앱입니다. 앱 표시 이름은 `일정 위젯`, 패키지는 `com.schedulewidget.mobile`입니다.

**현재 버전: Ver 0.0 · 비공개 테스트 중**

## 먼저 하기

1. 시험용 APK `ScheduleWidget-mobile-notes.apk`를 저장소 관리자에게 받습니다. 정식 릴리스는 아직 없습니다.
2. 폰에서 APK를 열어 설치합니다. Android가 `출처를 알 수 없는 앱 설치` 허용을 물으면 허용합니다. 최소 Android 8.0(API 26)입니다.
3. 앱을 열고, 권한 요청이 뜰 때 필요한 것만 허용합니다. 알림(마감 알림·녹음), 마이크(녹음), 캘린더(기기 일정), 다른 앱 위에 표시(화면 위 캐릭터)가 있습니다.
4. 하단 탭 `달력 | 녹음 | 노트`로 이동합니다. 처음 쓸 기능은 [기능별 바로 쓰기](#기능별-바로-쓰기)에서 고릅니다.

다음 할 일: 하단 `노트` 탭 → `새 노트`를 눌러 첫 노트를 만듭니다. (약 1분)

## 기능별 바로 쓰기

### 노트 쓰기

1. 하단 `노트` 탭 → `새 노트`.
2. `새 노트`(속지·A4 세로/가로 선택) 또는 `파일 가져오기`(PDF·PPT·Word·사진)를 고릅니다.
3. 열린 편집기에서 S펜으로 씁니다. 1초마다 자동 저장됩니다.
4. 끝나면 `⋮ 메뉴` → `PDF로 저장` 또는 `PDF 공유`.

`.flex`·`.flx` 파일은 `새 노트` → `.flex/.flx 노트 가져오기`에서 가져옵니다. 자세한 내용은 [노트 자세히](#노트-자세히).

### 일정 넣기

1. 하단 `달력` 탭에서 날짜를 누릅니다.
2. 일정을 추가합니다. 시간(`HH:mm`)과 카드 색은 선택입니다.
3. 여러 날 일정은 `연속 날짜`에서 시작일·종료일을 고릅니다.

보기 방식은 달력 위 기간 표시를 눌러 바꿉니다. 자세한 내용은 [달력과 할 일 자세히](#달력과-할-일-자세히).

### 캐릭터 켜기

1. 설정 → `캐릭터 설정`.
2. `캐릭터 표시`를 켭니다. 기본은 흰 모찌입니다.
3. 캐릭터를 한 번 누르면 말풍선 메뉴(앱 바로가기·음악·달력·설정·노트)가 열립니다.
4. 앱을 닫아도 남기려면 `화면 위에 펫 띄우기`를 켜고 `다른 앱 위에 표시` 권한을 허용합니다.

자세한 내용은 [캐릭터 자세히](#캐릭터-자세히).

### 수업 녹음하기

1. 설정 → `수업 녹음`에서 `수업 녹음 기능`을 켜고 마이크 권한을 허용합니다. (기본값은 켜짐)
2. `받아쓰기 모델`을 한 번 내려받습니다. 처음에는 가장 작은 `SenseVoice`(약 228MB, 기본)를 권장하며 Wi-Fi가 좋습니다.
3. 캐릭터를 **세 번** 누르면 녹음이 시작됩니다. 녹음 중에는 **두 번** 눌러 멈춥니다. 알림의 `정지`로도 멈춥니다.
4. 하단 `녹음` 탭 → 녹음 카드의 `받아쓰기`.

자세한 내용은 [수업 녹음과 받아쓰기 자세히](#수업-녹음과-받아쓰기-자세히).

### 음악 듣기

1. 설정 → `플레이리스트` → 새 플레이리스트를 만듭니다.
2. `파일 추가`·`폴더 추가`·`YouTube·Spotify 링크`로 곡을 담습니다.
3. 곡을 눌러 재생합니다.

YouTube 곡을 광고 없이 들으려면 [음악 자세히](#음악-자세히)의 Premium 항목을 확인합니다.

### 위젯 붙이기

1. 홈 화면의 빈 곳을 길게 누르고 `위젯`을 엽니다.
2. `일정 위젯`에서 미니 달력·음악 막대·플레이리스트 중 하나를 고릅니다.

## 기능 자세히

### 노트 자세히

<details>
<summary>목록·가져오기·내보내기</summary>

- **목록**: 폴더 카드와 현재 폴더의 노트를 표시합니다. `노트 홈`과 상위 폴더 경로를 눌러 이동하고, 뒤로가기로 한 단계 올라갑니다. 제목 검색은 전체 노트에서 찾으며 정렬은 `최근 수정`/`이름`입니다. 새 노트와 새 폴더는 현재 폴더 안에 생기고, 폴더를 지우면 내용은 상위 폴더로 이동하며 노트는 남습니다.
- **노트 카드 `⋮`**: `이름 바꾸기`, `폴더로 이동`, `PDF로 내보내기`, `삭제`(두 번 눌러 확인).
- **새 노트**: 속지 `무지·줄·모눈·점`, 크기 `A4 세로`/`A4 가로`.
- **파일 가져오기**: PDF·PPT·Word·사진(JPEG·PNG·WebP·HEIC 등)을 여러 개 한 번에 가져옵니다. `폴더 통째로 가져오기`는 선택한 폴더 아래의 PDF·PPTX·DOCX·`.flex`·`.flx`를 찾습니다. 일반 문서들은 현재 노트 폴더에 들어가고, 백업은 각 백업의 폴더를 만듭니다. 일반 파일 가져오기는 확장자와 MIME만 믿지 않고 파일 내용도 확인합니다. 가져오는 중에는 `취소`할 수 있습니다.
- **다른 앱에서 보내기**: PDF·PPT·Word·`.flex`/`.flx`를 다른 앱의 `열기`/`공유`에서 이 앱으로 보내면 가져옵니다. 설정 → `노트`에서 노트 기능이 켜져 있어야 하고, `content://` 항목만 받습니다.
- **PPT·Word 변환**: 설정 → `노트` → `PPT·Word 변환 방식`.
  - `자동`: 문서 업로드 동의와 구글 Drive 권한이 있으면 Drive, 아니면 폰에서 변환합니다.
  - `구글 드라이브`: 별도의 문서 업로드 동의 후 Drive에서 PDF로 바꿉니다. 인터넷과 구글 로그인이 필요합니다. 변환 뒤 임시 사본을 지우지만 오류가 나면 Drive에 남을 수 있습니다.
  - `폰에서`: 인터넷 없이 변환합니다. 글자·그림·표 위주로 단순하게 그려져 모양이 다를 수 있습니다.
  - 예전 형식 `.ppt`/`.doc`은 폰 변환이 안 되고 구글 Drive 변환만 가능합니다.
- **PDF 내보내기**: 필기를 포함한 PDF를 만듭니다. 페이지 일부만 내보낼 수도 있습니다.
- **진단 정보**: 가져오기에 문제가 있으면 `진단 정보 공유`로 보낼 수 있습니다. 파일 이름·크기·오류 종류가 들어갈 수 있으니 보내기 전에 확인합니다. 문서 본문·필기·토큰은 넣지 않습니다.

</details>

<summary>편집기: 도구·페이지·저장</summary>

- **상단 줄**: 뒤로, 제목(눌러서 이름 바꾸기), `실행 취소`/`다시 실행`(최대 200단계), 녹음 시작·중지, `페이지`, `⋮ 메뉴`.

- **펜**: 만년필·볼펜·연필·붓펜·형광펜, 슬롯 최대 12개. 선택된 펜을 한 번 더 누르거나 길게 누르면 색·굵기·복제·기본값·삭제·순서 설정이 열립니다. 형광펜은 멈춰 누르면 직선이 됩니다.
- **지우개**: `획 지우개`/`부분 지우개`. **올가미**: 둘러싸서 선택 → 이동·복제·삭제. **텍스트**: 페이지를 눌러 글상자를 넣고 크기(작게/보통/크게/제목)와 색을 고릅니다.
- **페이지 시트**(`페이지`): 누르면 이동, 길게 눌러 끌면 순서 변경. `선택`으로 여러 쪽을 골라 복제·회전·맨 앞/뒤 이동·다른 노트로 복사 또는 새 노트로 추출·PDF 내보내기·배경 바꾸기·필기 지우기·삭제를 할 수 있습니다. 삭제는 실행 취소로 되돌립니다. 마지막 한 쪽은 지울 수 없습니다.
- **페이지 추가**: 위치 `앞에`/`뒤에`/`맨 끝에`. 빈 페이지는 속지(`빈 종이`·`줄`·`모눈`·`점`·`코넬`·`오선지`), 크기(`현재와 같게`/`A4 세로`/`A4 가로`/`정사각`), 종이색(`흰색`/`아이보리`/`다크`)을 고릅니다. 다른 파일에서는 PDF·사진·카메라·다른 노트·PPT·Word를 넣을 수 있습니다. PDF 페이지의 배경은 바꿀 수 없습니다.
- **마지막 페이지 아래로 당기기**: 끝에서 더 아래로 스크롤하면 화면이 살짝 늘어납니다. 짧게 당기고 놓으면 되돌아오고, 충분히 당긴 뒤 놓으면 같은 크기의 빈 페이지가 한 장 추가됩니다. 필기·올가미·다중 터치 중에는 추가하지 않습니다. 자동 저장 중에도 동작합니다.
- **펜 측면 버튼**: 누른 채 쓰면 임시 지우개, 놓으면 직전 펜으로 돌아옵니다. 빠르게 두 번 누르면 펜·지우개 모드가 전환됩니다. 태블릿이 전달하는 버튼 이벤트를 사용하므로 기기에 따라 다를 수 있습니다.
- **손가락 필기**: 기본은 꺼짐입니다. 꺼져 있으면 S펜으로만 쓰고 손가락은 넘기기·확대에 씁니다. 손가락으로 쓰는 중에도 펜 입력이 우선합니다.
- **녹음 연동**: 수업 녹음이 켜져 있으면 편집기에서 녹음을 시작할 수 있고, `녹음 연동`을 켜면 필기를 눌렀을 때 그때의 녹음을 재생합니다.
- **자동 저장과 안전장치**: 1초 뒤 저장하고, 화면을 떠나거나 외부로 보낼 때 저장 성공을 기다립니다. 저장에 실패하면 안내와 `다시 시도`가 나옵니다. 삭제한 노트가 늦은 저장으로 되살아나지 않으며, 손상된 필기 파일은 빈 필기로 덮어쓰지 않고 열기를 실패 처리해 원본을 보존합니다.

<details>
<summary>.flex·.flx 복원과 노트 속 캐릭터</summary>

- `.flex` 백업은 파일 이름의 폴더 안에 원래 하위 폴더와 노트를 복원합니다. 완료 후 `폴더 열기`로 전체 노트를 확인하고 각 노트를 눌러 연결된 PDF와 필기를 엽니다. 같은 백업을 다시 가져오면 `(2)`처럼 새 폴더를 만듭니다.
- `.flx` 문서는 원본 노트 하나로 복원합니다. 페이지 순서, 여러 PDF 배경과 빈 페이지를 유지하고, 지원하는 필기는 편집 가능한 획으로 저장합니다. 백업의 별도 PDF도 누락하지 않으며, 가져온 필기는 수정하거나 지울 수 있습니다.
- 원본 노트 앱의 `설정 → 백업 → .flex 파일 만들기`로 만든 파일을 고르면 노트별로 복원합니다(추천). 문서 하나만 옮길 때는 `.flx` 원본으로 내보내 고릅니다. 가져온 컨테이너에 원본 `.flx`가 있으면 노트 폴더에 보관합니다.
- 지원하지 않는 이미지·도형 객체와 손상된 문서는 결과 창에 안내하고, 다른 정상 문서는 계속 복원합니다. 암호가 걸린 PDF도 안내합니다.
- PDF로 내보낸 파일도 열 수 있지만, 이미 PDF에 합쳐진 필기는 별도 필기로 되돌릴 수 없습니다.
- 폴더로 풀린 백업에는 원본 `.flx`가 없어 원본 보관은 보장하지 않습니다.
- **노트와 캐릭터**: 캐릭터 말풍선의 `노트` 버튼으로 노트 목록을 엽니다. 캐릭터 표시를 켜 두면 노트 목록과 편집기에서도 캐릭터가 보이며, 캐릭터별 숨김 설정도 적용됩니다. 편집 중 말풍선으로 다른 화면을 열 때는 저장 성공을 기다립니다.

</details>

### 달력과 할 일 자세히

<details>
<summary>달력 보기·할 일·애니메이션·마감 알림</summary>

- **보기 방식**: 달력 머리띠의 기간 표시를 눌러 고릅니다. 화살표는 고른 간격만큼 이동합니다.
  - `월간`: 월요일부터 시작하는 6주 격자. 칸마다 일정을 3개까지 보여 주고, 날짜를 누르면 전체 목록이 열립니다.
  - `주간`: 월~일을 한 줄에 하루씩 **세로로** 보여 줍니다.
  - `사용자 설정`: 1~14일 중 원하는 간격으로, 고른 날짜부터 **가로로** 보여 줍니다. 폭이 좁으면 좌우로 스크롤되고 오늘이 맨 왼쪽에 옵니다.
- **공휴일과 테마**: 한국 공휴일(음력·대체공휴일 포함)을 표시하고, 테마 5종을 고를 수 있습니다.
- **할 일**: 날짜를 누르면 그날 일정을 보고 바로 추가합니다. 추가·수정·삭제·완료, 선택 시간(`HH:mm`), 카드 색을 지원합니다. 달력·위젯·펫 달력의 일정 옆에 **D-day**(D-3, D-day, D+1)가 표시됩니다. 설정에서 D-day 표시와 달력 글자 크기를 바꿀 수 있습니다.
- **여러 날 일정**: `연속 날짜`에서 시작일·종료일을 고르면, 날짜마다 복사하지 않고 PC와 같은 `Period`·`EndPeriod`를 가진 일정 하나로 저장합니다. 기간 중 모든 날짜에 표시되고 완료·삭제는 전체 기간에 적용됩니다. D-day는 시작 전에는 시작일, 진행 중에는 `D-day`, 종료 후에는 종료일 기준입니다. 날짜를 옮기면 기간 길이를 유지합니다. 예전 버전의 날짜별 반복 항목은 그대로 유지됩니다.
- **다음 일정**: `›`를 길게 누르거나 `다음 일정`을 누르면 표시 기간 다음에 시작하는 미완료 일정을 봅니다. 기본은 28일 안의 12개이고, 없으면 가장 가까운 날짜의 일정을 보여 줍니다. `+N개 더`로 펼치고 항목을 눌러 수정합니다.
- **넘김 애니메이션**: 설정에서 효과 1~6 또는 `없음`을 고릅니다. PC의 `MiniFlipEffect` 설정도 가져옵니다. 시스템에서 애니메이션을 끄면 즉시 전환합니다.
- **마감 알림**: 설정 → `마감 알림`에서 켭니다. 며칠 전(당일~30일 전)과 알림 시각을 고르며, 시간이 정해진 일정은 일정 시각에 알립니다. 알림 권한과 정확한 알람 허용이 필요하고 `테스트 알림`으로 확인할 수 있습니다.

</details>

### 구글 캘린더와 기기 캘린더

<details>
<summary>구글 캘린더 양방향 연동 (PC와 같음)</summary>

설정 → `구글/기기 캘린더 연동` 맨 위의 `구글 캘린더 연동 (PC와 같음)` 스위치를 켜고 PC와 같은 구글 계정을 고릅니다. 할 일과 그 계정의 기본 구글 캘린더를 **양방향**으로 맞춥니다. 규칙과 저장 필드(`GoogleEventId` 등)는 PC 앱과 같습니다.

- 한쪽에서 바뀐 일정은 다른 쪽에도 반영되고, 둘 다 바뀌었으면 휴대폰 쪽이 이깁니다.
- 할 일을 지우면 이 앱이나 PC 위젯이 만든 참석자 없는 구글 일정만 함께 지워집니다. 구글에서 만든 일정·참석자가 있는 일정·반복 일정은 앱에서만 빠집니다. 삭제 확인에 구글에서의 처리도 표시되며, 일시적인 연결 실패는 다음 동기화에 재시도합니다. 구글에서만 지운 일정은 할 일로 남습니다.
- 여러 날 일정도 구글 일정 하나로 맞춥니다. 종일 일정의 종료일과 시간 지정 일정의 길이를 유지하고, 제목만 고치면 구글의 설명·참석자·기간을 덮어쓰지 않습니다.
- 처음 켤 때 제목·날짜·시간이 같은 구글 일정이 이미 있으면 새로 만들지 않고 그 일정과 연결합니다.
- 일정을 바꾸면 몇 초 뒤, 그리고 15분마다 자동으로 맞춥니다.
- 계정 확인에 실패하면 동기화를 중단합니다. 연결을 끊어도 Google 계정에 준 앱 권한은 자동으로 취소되지 않습니다. [구글 로그인과 개인정보](#구글-로그인과-개인정보)를 참고합니다.

</details>

<details>
<summary>기기 캘린더 표시 (구글·삼성 캘린더 앱)</summary>

설정 → `구글/기기 캘린더 연동`에서 켭니다. 휴대폰에 동기화된 구글 계정 캘린더와 삼성·기본 캘린더를 모두 읽으며 따로 로그인할 필요가 없습니다.

- 캘린더 일정을 달력·위젯·펫 달력에 함께 표시합니다. 누르면 캘린더 앱에서 열립니다.
- 할 일을 캘린더로 내보내거나, 추가·수정·삭제할 때 자동으로 저장하게 할 수 있습니다.

- 캘린더 권한(읽기·쓰기)이 필요합니다.

### 캐릭터 자세히

<details>
<summary>캐릭터 목록·조작·동작</summary>

- **번들 캐릭터**: 흰·검은·파란·빨간 모찌 4종입니다. 새로 시작하면 흰 모찌가 선택됩니다. 예전에 선택해 둔 기본 캐릭터가 앱에 더는 없으면 기존 대체 동작으로 흰 모찌로 표시됩니다.
- **슬롯**: 최대 3마리를 함께 표시합니다. 캐릭터마다 동작·크기·보이기·좌우 반전을 따로 설정하고, `이 펫 초기화`/`이 펫 삭제`가 있습니다. 끌어 놓은 위치는 캐릭터별로 기억하며, 바꾸거나 다시 추가하면 이전 자리로 돌아옵니다.
- **동작**: `대기`·`인사`·`점프`·`활동`·`왼쪽 걷기`·`오른쪽 걷기`·`기다리기`·`집중`·`당황`과, 캐릭터가 지원할 때 `음악 듣기`·`신남`·`싫어함`·`심취`·`키보드 1/2`, 그리고 `음악 반복`·`타이핑 반응`·`랜덤 순회`가 있습니다. `음악 반복`은 재생 중에 음악 동작만 순회하고 멈추면 대기로 돌아갑니다. `타이핑 반응`은 앱 안에서 입력할 때마다 장면을 넘기고 약 0.9초 입력이 없으면 대기로 돌아갑니다. 입력 내용은 기록하지 않습니다.
- **말풍선 바로가기**: 앱을 최대 3개까지 넣을 수 있고 `음악`·`달력`·`설정`은 항상 있습니다. 노트 기능이 켜져 있으면 `노트`도 있습니다. 수업 녹음이 켜져 있으면 말풍선을 옆으로 넘겨 2쪽(녹음 시작·정지, 음질·마이크·모델, 최근 받아쓰기)을 볼 수 있습니다. 순천향톡이 설치되어 있으면 `모바일 신분증` 바로가기를 설정할 수 있으며, 신분증 화면까지 자동으로 여는 기능은 접근성 설정을 켜야 동작합니다.

| 조작 | 앱 안의 캐릭터 | 화면 위 캐릭터 |
| --- | --- | --- |
| 한 번 누르기 | 반응 동작 + 말풍선 메뉴 열기/닫기 | 반응 동작 + 말풍선 메뉴 |
| 두 번 누르기 | 녹음 중이면 정지 | 녹음 중이면 정지, 아니면 7일 달력 패널 |
| 세 번 누르기 | `수업 녹음` 켜짐: 녹음 시작 / 꺼짐: MP3 도구 | 같음 |
| 길게 누르기 | 화면 위로 내보내기 | 끌어서 이동 (놓는 자리 기억) |

- 미니 달력 화면의 말풍선에는 `달력 보이기` 스위치가 있어 달력을 숨기거나 보입니다.
- **MP3 도구**: 음악 막대와 현재 플레이리스트 곡 목록입니다. 한 줄 미니 플레이어로 시작해 `⌃`로 펼칩니다.

</details>

<details>
<summary>화면 위 캐릭터·펫 달력·가져오기·Drive 동기화</summary>

- **화면 위에 띄우기**: 캐릭터 설정의 `화면 위에 펫 띄우기`를 켜거나 앱 안의 캐릭터를 길게 누르면 켜집니다. 화면 위 캐릭터를 **꾹 누르면** 아래 가운데에 ✕가 나타나고, 캐릭터를 그 위에 놓으면 사라집니다. 앱을 닫아도 홈 화면과 다른 앱 위에 남고 재부팅 뒤에도 다시 나타납니다. 처음 한 번 **다른 앱 위에 표시** 권한이 필요하고, 알림창의 `펫 숨기기`로 끌 수 있습니다.
- **펫 달력 패널**: 오늘부터 7일을 **가로로** 보여 주며 좌우로 넘깁니다. 날짜 옆 `⚙ 펫`은 캐릭터 설정을 열고, `+ 일정`은 일정을 바로 추가하고, `앱 열기`는 앱으로 이동합니다. 날짜 칸을 누르면 그날 일정을 추가합니다. 오른쪽 아래 `⤡`를 끌면 크기가 바뀌고 다음에도 그 크기로 열립니다.
- **캐릭터 가져오기**(캐릭터 설정): 가져온 캐릭터는 앱 저장소에 복사되어 목록에 추가되고, 타일의 ✕로 삭제합니다.
  - `pet.json · .zip`: PC 앱의 `캐릭터 내보내기`로 만든 `.zip`을 고르거나, `pet.json`과 스프라이트 이미지를 함께 고릅니다. 이미지를 빼고 고르면 이어서 물어봅니다.
  - `캐릭터 폴더`: PC의 `%LocalAppData%\ScheduleWidget\Pet\<캐릭터>` 폴더를 휴대폰에 옮긴 뒤 그 폴더를 고릅니다.
  - 스프라이트시트는 PC와 같은 v1~v5(너비 1536, 높이 1872·2288·2704·3120·3536)를 지원합니다. 사진·PNG·WebP·GIF 이미지도 캐릭터로 쓸 수 있으며 정지 그림으로 표시됩니다(GIF는 첫 장면만).
  - `PC에서 가져오기`로 `schedules.json`을 가져오면 모찌와 캐릭터별 설정을 이어서 사용합니다. PC에서 가져온 사용자 캐릭터는 휴대폰에도 먼저 가져와 두면 이어집니다.
- **구글 드라이브 캐릭터 보관**: 캐릭터 설정의 `PC 앱과 캐릭터 동기화`를 켜고 PC와 같은 구글 계정으로 로그인하면, PC에서 가져온 캐릭터가 폰으로 오고 폰에서 가져온 캐릭터가 PC로 갑니다. `drive.file` 권한만 씁니다.
  - 한쪽에서 삭제한 캐릭터는 드라이브에서도 지웁니다.
  - 드라이브에서만 지운 캐릭터는 폰에 남습니다.
  - 이름이 같은 캐릭터는 중복해서 받지 않습니다.
  - 스위치를 꺼도 자동 동기화만 멈추고, Google 계정 권한과 Drive 파일은 남습니다 (`Google 계정 권한 관리` 링크 제공).

</details>

### 수업 녹음과 받아쓰기 자세히

<details>
<summary>녹음 설정과 사용</summary>

설정 → `수업 녹음`의 항목입니다.

- `수업 녹음 기능`(기본 켜짐): 켜면 캐릭터 세 번 = 시작, 녹음 중 두 번 = 정지, 말풍선 2쪽, `녹음` 탭이 활성화됩니다.
- `음질`: `표준`(44.1kHz·96kbps, 1시간 약 43MB), `고음질`(48kHz·128kbps, 약 58MB, 기본), `최고`(48kHz·192kbps, 마이크가 2개 이상이면 스테레오, 약 86MB).
- `녹음 마이크`: `기본`(자동 음량 조절), `원거리(강의실)`, `처리 최소`(잡음 제거·자동 음량 없음).
- `마이크 음량`(녹음 입력, 50~400%)과 `스피커 음량`(앱 안 재생 전용)은 별개입니다. 입력이 너무 크면 경고가 나옵니다.
- 녹음은 화면을 꺼도 계속되고 알림에 `정지` 버튼이 있습니다. 파일 이름은 `수업_날짜_시각.m4a` 형식입니다. 너무 짧은 녹음은 저장하지 않고, 저장 공간이 부족하면 멈추고 그때까지를 저장합니다.
- 녹음 목록(`녹음` 탭 또는 `녹음 목록`): 재생, `받아쓰기`/`받아쓰기 보기`/`다시 받아쓰기`, `이름`, `공유`, `삭제`(한 번 더 눌러 확인). 재생 화면에는 `증폭`(100% 이상, MP3 도구와 같은 설정)과 `자막`(크기 작게/보통/크게)이 있습니다.

</details>

<details>
<summary>받아쓰기 모델·화자 분리·전사본 편집</summary>

- **모델**: 인터넷 없이 휴대폰 안에서 받아씁니다. 쓸 모델을 처음 한 번 내려받습니다(Wi-Fi 권장). 모델 파일은 외부 배포 서버에서 받고, 이때 녹음 내용은 보내지 않습니다. 앱 설정의 `모델이 차지하는 공간`에서 용량을 보고 삭제할 수 있습니다.

| 모델 | 크기 | 특징 |
| --- | --- | --- |
| `SenseVoice` | 약 228MB | 빠름·정확 (기본) |
| `Whisper small` | 약 357MB | 중간 |
| `Qwen3-ASR 0.6B` | 약 941MB | 정확, 숫자를 한글로 씀 |
| `Whisper turbo` | 약 988MB | 가장 정확·느림, 메모리 2GB 필요 |

- YouTube 재생목록 로그인은 Drive 권한과 함께 요청할 때 생기던 오류를 피하려고 PC 설치형 클라이언트의 브라우저 로그인(PKCE·루프백)을 그대로 씁니다. Android 클라이언트용 루프백 흐름은 Google이 지원하지 않으므로, 이 Desktop 클라이언트 재사용 방식의 공개 배포 적합성은 **별도로 확인해야 합니다**. 실제 Google 계정으로 두 기능을 함께 검증하기 전에는 인증 방식을 일괄 교체하지 않습니다.
- `drive.file`은 같은 앱 프로젝트가 만들거나 사용자가 허용한 파일만 다룹니다. PC 앱이 올린 캐릭터와 연동하려면 같은 프로젝트 등록이어야 합니다.
- 앱의 연결 해제·로그아웃은 자동 작업과 저장된 로그인 상태를 멈출 뿐, Google 계정에 준 권한을 자동으로 취소하지 않습니다. `https://myaccount.google.com/connections`에서 취소합니다.
- 로그인 토큰과 문서 업로드 동의 저장소는 클라우드 백업·기기 이전에서 제외됩니다.
- 정책 원문을 고친 뒤 `tools/generate_privacy.py`를 실행하면 앱 내 정책 텍스트와 `docs/privacy.html`을 함께 갱신합니다.

</details>

## 빌드와 테스트

PowerShell에서 `ScheduleWidget-mobile-notes` 폴더(저장소 루트)로 이동해 실행합니다. JDK는 Android Studio에 포함된 것을 씁니다. 최소 Android 8.0(API 26), 대상 API 36, 지원 ABI `arm64-v8a`·`x86_64`.

1. 폴더로 이동하고 JDK를 지정합니다.

```powershell
Set-Location '<ScheduleWidget-mobile-notes 폴더 경로>'
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
```

2. debug APK를 빌드합니다. 결과: `app\build\outputs\apk\debug\app-debug.apk`

```powershell
.\gradlew.bat :app:assembleDebug
```

3. 폰(또는 에뮬레이터)에 설치합니다.

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

단위 테스트와 lint:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

## 릴리스 절차

관리자용입니다. 앱 업데이트 기능이 새 버전을 받으려면 아래 조건이 **모두** 맞아야 합니다. 이 README는 절차만 설명하며 릴리스를 게시하지 않습니다.

| 조건 | 값 |
| --- | --- |
| 버전 이름 | `0.1` (숫자 형식) |
| 버전 코드 | `4` 이상 (현재 설치본 3보다 커야 함) |
| 서명 키 | 설치된 앱과 같은 키 |
| 태그 | 숫자 태그 `v0.1` (`versionName`과 숫자가 같아야 함) |
| 자산 | 게시된 정식 릴리스의 `ScheduleWidget-mobile-notes.apk` (SHA-256 digest 표시됨) |

초안·사전 릴리스는 업데이트 대상이 아닙니다.

1. `app/build.gradle.kts`에서 `versionCode`를 4 이상으로, `versionName`을 `"0.1"`로 바꿉니다. (`versionName`은 0.0부터 다시 시작하지만 `versionCode`는 계속 올려야 기존 설치본을 덮어씁니다.)
2. release 서명 환경 변수 4개를 현재 PowerShell 세션에만 설정합니다. 값은 저장소·로그에 남기지 않습니다. 키스토어 경로를 설정했는데 나머지 값이 없으면 빌드가 중단되고, 키스토어 경로가 없으면 release가 서명되지 않습니다. release는 debug 키로 대신 서명하지 않습니다.

```powershell
$env:SCHEDULEWIDGET_KEYSTORE = '<키스토어 파일 경로>'
$env:SCHEDULEWIDGET_STORE_PASSWORD = '<저장소 비밀번호>'
$env:SCHEDULEWIDGET_KEY_ALIAS = '<키 별칭>'
$env:SCHEDULEWIDGET_KEY_PASSWORD = '<키 비밀번호>'
```

3. 설치된 앱의 서명 인증서와 같은 키인지 확인합니다.

```powershell
.\gradlew.bat :app:signingReport
```

4. release APK를 빌드합니다. 서명되지 않은 결과(`-unsigned`)는 설치·배포에 쓰지 않습니다.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
```

5. `app\build\outputs\apk\release\app-release.apk`라는 서명된 결과만 이름 `ScheduleWidget-mobile-notes.apk`로 복사하고 SHA-256을 구합니다. `-unsigned` 결과는 사용하지 않습니다.

```powershell
$releaseApk = '.\app\build\outputs\apk\release\app-release.apk'
if (-not (Test-Path -LiteralPath $releaseApk)) { throw '서명된 release APK가 없습니다. release 서명 환경 변수를 확인하세요.' }
Copy-Item -LiteralPath $releaseApk -Destination '.\ScheduleWidget-mobile-notes.apk'
Get-FileHash -LiteralPath '.\ScheduleWidget-mobile-notes.apk' -Algorithm SHA256
```

6. GitHub에서 태그 `v0.1`로 릴리스를 만들고 위 APK 하나만 올린 뒤 **초안·사전 릴리스 체크 없이** 게시합니다. 게시 뒤 자산의 SHA-256 표시가 5번 결과와 같은지 확인합니다.
7. 이전 버전이 설치된 폰에서 설정 → `앱 업데이트` → `업데이트 확인`으로 실제 설치까지 확인합니다. 저장소가 비공개인 동안은 토큰이 필요합니다.
8. 구글 로그인을 쓰려면 release 인증서의 SHA-1을 OAuth Android 클라이언트에 추가합니다([구글 로그인과 개인정보](#구글-로그인과-개인정보) 참고).

debug 서명으로 만든 시험 APK는 같은 debug 인증서로 설치된 앱만 업그레이드합니다. 키와 비밀번호, 개인 문서, 로그인 토큰은 저장소에 올리지 않습니다.

## 알려진 제한

1. `앱 안에서` 방식으로 재생한 YouTube 곡은 앱을 백그라운드로 보내면 멈출 수 있습니다. 광고 없이 백그라운드에서 들으려면 YouTube Music 앱 방식을 씁니다.
2. YouTube Music 앱 방식은 곡마다 그 앱이 앞으로 열립니다.
3. GIF 캐릭터는 첫 프레임만 보입니다. 타이핑 반응은 앱 안에서만 동작합니다.
4. 앱 업데이트: 이어받기가 없고, 서명 인증서 교체는 지원하지 않으며, 설정 화면이 다시 만들어지면 상태와 토큰이 사라집니다. 게시된 정식 릴리스가 생기기 전에는 실제 GitHub 릴리스로 끝까지 설치되는지 확인되지 않았습니다.
5. 저장이 실패한 상태에서 화면이 다시 만들어지면 저장하지 못한 메모리 내용이 남지 않을 수 있습니다(실패는 안내합니다).

<details>
<summary>그 밖의 제한</summary>

- 녹음 백업 `.fab` 복원은 구현하지 않았습니다.
- 자막 파일(.srt/.vtt) 내보내기는 지원하지 않습니다.
- 이전 버전이 구글 Drive에 남긴 표식 없는 문서 변환 임시 사본은 앱이 찾아 지우지 못하므로 Drive에서 직접 확인해야 합니다. 이 버전이 표식을 붙인 사본은 이후 구글 변환 때 일정 시간이 지난 것부터 정리를 다시 시도합니다.
- 펜 버튼은 표준 MotionEvent와 삼성 접촉 이벤트를 처리합니다. 실제 태블릿이 버튼을 전달하는 방식은 기기마다 다를 수 있습니다.
- 실제 구글 계정에서 캘린더·Drive·YouTube를 함께 쓰는 로그인은 이 README 작성 중 검증하지 않았습니다.

</details>
