# ScheduleWidget Notes (Android)

Android 노트 버전입니다. 노트 필기·문서 가져오기와 달력, 할 일, 녹음, 음악, 캐릭터를 함께 제공합니다. 현재 비공개 테스트 중이며 업로드 저장소는 [KIMY0UNGGON/ScheduleWidget-Moblie](https://github.com/KIMY0UNGGON/ScheduleWidget-Moblie)입니다.

## 미니 달력과 할 일

- **보기 방식**: 달력 머리띠의 기간 표시를 눌러 고릅니다. 화살표는 고른 간격만큼 이동합니다.
  - **월간**: 월요일부터 시작하는 6주 격자입니다. 칸마다 일정을 3개까지 보여 주고, 날짜를 누르면 전체 목록이 열립니다.
  - **주간**: 월~일을 한 줄에 하루씩 **세로로** 보여 줍니다(세로로 긴 휴대폰 화면용).
  - **사용자 설정**: 1~14일 중 원하는 간격으로, 고른 날짜부터 **가로로** 나란히 보여 줍니다. 폭이 좁으면 좌우로 스크롤되고 오늘이 맨 왼쪽에 옵니다.
- **공휴일과 테마**: 한국 공휴일(음력·대체공휴일 포함)을 표시하고, 테마 5종을 고를 수 있습니다.
- **할 일**: 날짜를 누르면 그날 일정을 보고 바로 추가할 수 있습니다. 추가·수정·삭제·완료, 선택적 시간(`HH:mm`), 카드 색상을 지원합니다. 달력, 위젯, 펫 달력의 일정 옆에 **D-day**(D-3, D-day, D+1)가 표시됩니다.
- **여러 날 일정**: 추가·수정의 `연속 날짜`에서 시작일과 종료일을 고릅니다. 날짜마다 복사하지 않고 PC와 같은 `Period`·`EndPeriod`를 가진 일정 하나로 저장합니다. 달력·홈 화면 위젯·펫 달력에는 기간 중 모든 날짜에 표시되며, 완료·삭제는 전체 기간에 적용됩니다. D-day는 시작 전에는 시작일, 진행 중에는 `D-day`, 종료 후에는 종료일을 기준으로 계산합니다. 날짜를 옮기면 기간 길이를 유지합니다. 예전 버전에서 만든 날짜별 반복 항목은 그대로 유지됩니다.
- **다음 일정**: `›`를 길게 누르거나 `다음 일정`을 눌러 표시 기간 다음에 시작하는 미완료 일정을 봅니다. 기본은 28일 안의 12개이고, 그 안에 없으면 가장 가까운 날짜의 일정을 보여 줍니다. `+N개 더`로 이후 일정을 펼치고 항목을 눌러 수정할 수 있습니다.
- **넘김 애니메이션**: 설정에서 모바일 화면에 맞춘 효과 6가지 또는 `없음`을 고릅니다. PC의 `MiniFlipEffect` 설정도 가져오며, 시스템에서 애니메이션을 끄면 즉시 전환합니다. 달력을 숨기거나 일정·보기·테마가 바뀌면 진행 중인 효과를 끝냅니다.

## 구글 캘린더 연동 (PC와 같음)

설정 → `구글/기기 캘린더 연동` 맨 위의 `구글 캘린더 연동 (PC와 같음)` 스위치를 켜고 PC와 같은 구글 계정을 고릅니다. 켜면 할 일과 그 계정의 기본 구글 캘린더를 **양방향**으로 맞춥니다. 규칙과 저장 필드(`GoogleEventId` 등)는 PC 앱과 같아서, PC·휴대폰·구글 캘린더가 같은 일정 목록을 보여 줍니다.
- 한쪽에서 바뀐 일정은 다른 쪽에도 반영되고, 둘 다 바뀌었으면 휴대폰 쪽이 이깁니다.
- 할 일을 지우면 이 앱이나 PC 위젯이 만든 참석자 없는 구글 일정만 함께 지워집니다. 구글에서 만든 일정·참석자가 있는 일정·반복 일정은 앱에서만 빠집니다. 삭제 확인에 구글에서의 처리도 표시되며, 일시적인 연결 실패는 다음 동기화에 재시도합니다. 구글에서만 지운 일정은 할 일로 남습니다.
- 여러 날 일정도 구글 일정 하나로 맞춥니다. 종일 일정의 종료일과 시간 지정 일정의 길이를 유지하고, 제목만 고치면 구글의 설명·참석자·기간을 덮어쓰지 않습니다.
- 처음 켤 때 제목·날짜·시간이 같은 구글 일정이 이미 있으면, 새로 만들지 않고 그 일정과 연결합니다.
- 일정을 바꾸면 몇 초 뒤, 그리고 15분마다 자동으로 맞춥니다.

## 기기 캘린더 표시 (구글·삼성 캘린더 앱)

설정 → `구글/기기 캘린더 연동`에서 켭니다. 휴대폰에 동기화된 구글 계정 캘린더와 삼성·기본 캘린더를 모두 읽으며, 따로 로그인할 필요가 없습니다.
- 캘린더 일정을 달력·위젯·펫 달력에 함께 표시합니다. 누르면 캘린더 앱에서 열립니다.
- 할 일을 캘린더로 내보내거나, 추가·수정·삭제할 때 자동으로 저장하게 할 수 있습니다.
- 기기 캘린더의 30일치 일정을 할 일로 가져올 수 있습니다.

## 캐릭터(펫)

- **캐릭터 목록**: 흰·검은·파란·빨간 모찌 4종과 기존 캐릭터 9종을 포함합니다. 새로 시작하면 흰 모찌가 선택됩니다. 최대 3마리를 함께 표시하고, 캐릭터마다 동작·크기·보이기·좌우 반전을 따로 설정합니다. 끌어 놓은 위치는 캐릭터별로 기억하며, 바꾸거나 다시 추가하면 이전 자리로 돌아옵니다.
- **동작**: 선언된 음악·키보드 동작을 지원합니다. `음악 반복`은 재생 중에 음악 동작만 순회하고 멈추면 대기로 돌아갑니다. `타이핑 반응`은 앱 안에서 입력할 때마다 장면을 넘기고, 약 0.9초 동안 입력이 없으면 대기로 돌아갑니다. 입력 내용은 기록하지 않습니다.

| 조작 | 앱 안의 펫 | 화면 위 펫 |
| --- | --- | --- |
| 한 번 누르기 | 반응 동작 | 반응 동작 |
| 두 번 누르기 | 달력 숨기기/보이기 | 7일 달력 패널 |
| 세 번 누르기 | MP3 도구 | MP3 도구 |
| 길게 누르기 | 화면 위로 내보내기 | – |

- **MP3 도구**: 음악 막대와 현재 플레이리스트 곡 목록으로 이루어져 있습니다.
- **화면 위에 띄우기**: 캐릭터 설정의 `화면 위에 펫 띄우기`를 켜거나 앱 안의 펫을 길게 누르면 켜집니다. 화면 위 펫을 **꾹 누르면** 아래 가운데에 ✕가 나타나고, 펫을 그 위에 놓으면 펫이 사라집니다. 앱을 닫아도 홈 화면과 다른 앱 위에 남고, 재부팅 뒤에도 다시 나타납니다. 처음 한 번 **다른 앱 위에 표시** 권한이 필요합니다. 알림창의 `펫 숨기기`로 끌 수 있습니다.
- **펫 달력 패널**: 오늘부터 7일을 **가로로** 보여 주며 좌우로 넘길 수 있습니다. 날짜 옆 `⚙ 펫`을 누르면 캐릭터 설정이 바로 열립니다. `+ 일정`으로 일정을 바로 추가하고, `앱 열기`로 앱으로 이동합니다. 날짜 칸을 누르면 그날 일정을 추가합니다. 오른쪽 아래 `⤡`를 끌면 패널 크기가 바뀌고, 바꾼 크기는 저장되어 다음에 열 때도 그 크기로 열립니다.
- **캐릭터 가져오기**: 캐릭터 설정의 `캐릭터 가져오기`를 사용합니다. 가져온 캐릭터는 앱 저장소에 복사되어 목록에 추가되고, 타일의 ✕로 삭제할 수 있습니다.
  - `pet.json · .zip`: PC 앱의 `캐릭터 내보내기`로 만든 `.zip`을 고르거나, `pet.json`과 스프라이트 이미지를 함께 고릅니다. 이미지를 빼고 고르면 이어서 물어봅니다.
  - `캐릭터 폴더`: PC의 `%LocalAppData%\ScheduleWidget\Pet\<캐릭터>` 폴더를 휴대폰에 옮긴 뒤 그 폴더를 고릅니다.
  - 스프라이트시트는 PC와 같은 v1~v5(1536×1872·2288·2704·3120·3536)를 지원합니다. `PC에서 가져오기`로 `schedules.json`을 가져오면 모찌와 캐릭터별 설정을 이어서 사용합니다. PC에서 가져온 사용자 캐릭터는 휴대폰에도 먼저 가져와 두면 이어집니다.

## 음악

- **플레이리스트**: 데스크톱과 같은 구조입니다. 여러 목록을 만들 수 있고 음악 파일, 폴더, YouTube 링크를 섞어 담을 수 있습니다. 재생 방식은 순차·랜덤·1곡 반복입니다.
- **사이에 끼워 넣기**: 목록에서 곡을 **길게 누르면** 그 아래에 파란 선이 생깁니다. 이 상태에서 파일·폴더·링크·구글 재생목록을 추가하면 그 자리에 들어갑니다. `맨 뒤에 추가`를 누르면 원래대로 목록 끝에 추가됩니다. 이렇게 YouTube 재생목록 사이에 휴대폰 음악 파일을 끼운 나만의 목록을 만들 수 있습니다.
- **YouTube Music 링크와 공유**: youtube.com, youtu.be, music.youtube.com 링크를 모두 받습니다. YouTube나 YouTube Music 앱의 `공유`에서 **일정 위젯**을 고르면 앱을 열지 않고 원하는 플레이리스트에 추가됩니다.
- **YouTube 재생목록 가져오기**: 플레이리스트 화면의 `YouTube 재생목록`을 누르고 브라우저에서 한 번 로그인하면 계정의 재생목록이 보입니다. YouTube Music에서 만든 재생목록도 YouTube 재생목록이라 함께 나오고, 비공개 목록과 `좋아요 표시한 동영상`도 포함됩니다. 각 목록을 새 플레이리스트로 만들거나 표시한 위치에 넣을 수 있습니다. 로그인은 PC 앱과 같은 방식(브라우저 + PC 앱 OAuth 클라이언트)이고 YouTube 권한만 단독으로 요청해서, 드라이브 권한과 겹쳐 막히는 문제가 없습니다. Cloud 프로젝트에서 **YouTube Data API v3**를 켜 두어야 합니다.
- **재생 중 목록 가져오기**: YouTube Music(또는 YouTube)에서 음악을 재생하는 중에 플레이리스트 화면의 `재생 중 목록`을 누르면, 그 앱의 재생 대기열이 일회용 플레이리스트 `지금 재생 목록`으로 들어옵니다. 누를 때마다 새로 덮어씁니다. YouTube Music은 대기열에 곡 제목만 알려 주므로 제목과 아티스트로 YouTube에서 곡을 찾아 넣습니다. 지금 듣던 곡 다음이 삽입 위치로 잡혀 있어서, 바로 `파일 추가`를 누르면 그 사이에 휴대폰 음악 파일이 들어갑니다. 알림 접근 권한이 필요합니다.
- **Premium으로 재생(광고 없이)**: 기본값은 **YouTube Music 앱**이고, 플레이리스트 화면의 `YouTube 곡 재생`에서 바꿀 수 있습니다.
  - **앱 안에서**: 앱 안의 플레이어로 재생하며, 광고가 나올 수 있습니다.
  - **YouTube Music 앱 / YouTube 앱**: 공식 앱이 곡을 재생하므로 그 앱에 로그인한 **Premium 계정이 그대로 적용**됩니다. 광고가 없고 백그라운드에서도 재생됩니다. 곡이 끝나면 이 앱이 알아채고 다음 곡(휴대폰 파일 포함)으로 이어 갑니다. 자동으로 넘어가려면 **알림 접근** 권한이 필요합니다.
  - Premium을 API로 따로 "연동"하는 방법은 없고, 광고를 강제로 막는 것은 YouTube 약관 위반이라 지원하지 않습니다.
- **음악 앱 편집**: Spotify, YouTube Music, 멜론, 지니, FLO 등을 목록에 추가·삭제하고 순서를 바꿉니다. 음악 막대의 `재생 소스`에서 고른 앱을 조작할 수 있습니다.

## 데스크톱 데이터 옮기기

설정 → `PC에서 가져오기`에서 PC의 `%LOCALAPPDATA%\ScheduleWidget\schedules.json`을 고르면 일정과 플레이리스트를 가져옵니다. 기존 구글 연결 정보를 초기화하고 자동 동기화를 해제하므로, 가져온 내용을 확인한 뒤 캘린더를 다시 연결해 주세요. 파일 가져오기로 이전 구글 일정이 삭제되지 않도록 한 처리입니다.
- YouTube 곡은 그대로 재생됩니다.
- PC 파일 경로 곡은 `재연결 필요`로 표시됩니다. 곡의 `재연결`을 눌러 휴대폰 파일로 바꿔 주세요.

## 구글 로그인 설정 (1회)

구글 로그인 및 정책 등록 절차는 [GCP_SETUP.md](docs/GCP_SETUP.md)를 확인하세요. 지원 이메일은 `ddd84860@gmail.com`입니다. 정책은 [PRIVACY.md](PRIVACY.md)와 앱의 설정 > 개인정보에서 읽을 수 있습니다. 공개 홈페이지·정책용 HTML은 `docs/`에 준비했으며, 현재는 공개 게시하지 않았습니다.

구글 로그인은 다음 기능에서 씁니다.
- 캐릭터 설정 → `PC 앱과 캐릭터 동기화`: 구글 드라이브, `drive.file` 권한
- 캘린더 연동 → `구글 캘린더 연동`: `calendar.events`, `calendar.calendars.readonly` 권한
- 노트의 PPT·Word 구글 변환: `drive.file`과 별도의 문서 업로드 동의
- YouTube 재생목록 가져오기: `youtube.readonly`, 이메일 권한

기존 YouTube 경로는 Drive 권한과 함께 요청할 때 발생한 오류를 피하려고 PC 설치형 클라이언트의 브라우저 로그인을 사용합니다. Android 클라이언트용 루프백 흐름은 Google이 지원하지 않으므로, 이 Desktop 클라이언트 재사용 방식의 공개 배포 적합성은 별도로 확인해야 합니다. 실제 Google 계정의 두 기능을 함께 검증하기 전에는 인증 방식을 일괄 교체하지 않습니다.

`drive.file` 권한으로 같은 앱 프로젝트가 만들거나 사용자가 해당 앱에 허용한 파일을 관리합니다. PC 앱이 올린 캐릭터와 연동하려면 같은 프로젝트 등록을 확인해야 합니다. APK에는 설치형 OAuth 클라이언트 설정이 들어 있으며, 이는 비밀 저장소가 아닙니다. 사용자 토큰·release 서명 키를 저장소에 올리지 않습니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 PC 앱의 프로젝트 **`gen-lang-client-0088309798`**를 엽니다.
2. `API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID`에서 유형을 **Android**로 고르고 다음을 입력합니다.
   - 패키지 이름: `com.schedulewidget.mobile`
   - SHA-1 인증서 지문: `9A:16:08:76:BB:B1:A6:36:12:19:44:40:CB:8D:8C:11:2A:60:4F:F7` (이 PC의 디버그 서명. 다른 키로 서명하면 `./gradlew signingReport`로 확인)
3. Google Drive API, Google Calendar API와 YouTube Data API v3 활성화를 콘솔에서 확인합니다. 코드만으로 현재 설정을 확인할 수는 없습니다.
4. OAuth 동의 화면이 테스트 상태라면, 폰에서 쓸 구글 계정이 **테스트 사용자**에 들어 있는지 확인합니다.

등록 전에 로그인하면 로그인 창이 바로 닫히고 앱이 이 설정을 안내합니다. 등록 뒤에는 PC와 같은 계정으로 로그인하고 스위치를 켜면 됩니다. 그러면 PC에서 가져온 캐릭터가 폰으로 오고, 폰에서 가져온 캐릭터가 PC로 갑니다. 규칙은 PC와 같습니다.
- 한쪽에서 삭제한 캐릭터는 드라이브에서도 지웁니다.
- 드라이브에서만 지운 캐릭터는 폰에 남습니다.
- 이름이 같은 캐릭터는 중복해서 받지 않습니다.

## 빌드

Android Studio의 내장 JDK로 저장소 루트(로컬 작업 폴더에서는 `ScheduleWidget-mobile-notes`)를 열거나, 그 폴더에서 명령줄로 빌드합니다.

```bash
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
./gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

최소 Android 8.0(API 26), 대상 API 36.

## 노트와 펫

- 캐릭터 말풍선의 `노트` 버튼으로 노트 목록을 엽니다. 캐릭터 표시를 켜 두면 노트 목록과 편집 화면에서도 펫이 표시되며, 캐릭터별 숨김 설정도 적용됩니다. 편집 중 말풍선으로 다른 화면을 열 때는 저장 성공을 기다립니다.
- `.flex`·`.flx`는 원본 노트 단위로 복원합니다. 폴더, 페이지 순서, 여러 PDF 배경과 빈 페이지를 유지하고 지원하는 필기는 편집 가능한 데이터로 저장합니다. 가져온 컨테이너에 원본 `.flx`가 있으면 노트 폴더에 보관합니다. 지원하지 않는 이미지·도형 객체와 손상된 문서는 결과에 안내하고 다른 정상 문서는 계속 복원합니다. 이미 PDF에 합쳐진 필기는 별도 필기로 되돌릴 수 없습니다.
- 마지막 페이지 끝에서 더 아래로 스크롤하면 화면이 살짝 늘어납니다. 짧게 당기고 놓으면 되돌아오고, 충분히 당긴 뒤 놓으면 같은 크기의 빈 페이지가 한 장 추가됩니다. 필기·올가미·다중 터치 중에는 페이지를 추가하지 않습니다.
- 펜 측면 버튼을 누른 채 필기하면 임시 지우개가 됩니다. 놓으면 직전 펜 설정으로 돌아오며, 버튼을 빠르게 두 번 누르면 펜·지우개 모드가 전환됩니다. 펜 종류·색·굵기는 유지됩니다. 태블릿이 전달하는 버튼 이벤트를 사용합니다.

## 알려진 제한

- `앱 안에서` 방식으로 재생한 YouTube 곡은 앱을 백그라운드로 보내면 멈출 수 있습니다. 광고 없이 백그라운드에서 들으려면 YouTube Music 앱 방식을 쓰세요.
- GIF 캐릭터는 첫 프레임만 보입니다. 타이핑 반응은 앱 안에서만 동작합니다.
- YouTube Music 앱 방식은 곡마다 그 앱이 앞으로 열립니다.

앱 자체의 업데이트 확인·다운로드·설치 기능은 포함하지 않습니다.
