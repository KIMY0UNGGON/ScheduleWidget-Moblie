# 일정 위젯 · ScheduleWidget Notes

**설치하려면 [Ver 0.1.3 배포 페이지](https://github.com/KIMY0UNGGON/ScheduleWidget-Moblie/releases/tag/v0.1.3)에서 `ScheduleWidget-mobile-notes.apk`를 받으세요.** GitHub 로그인 없이 내려받을 수 있습니다.

[rnrdus5642/ScheduleWidget](https://github.com/rnrdus5642/ScheduleWidget)의 Windows 일정 위젯을 **Android로 옮기고 노트 필기 기능을 더한 모바일 버전**입니다.

Android에서 일정·할 일, 문서 필기, 수업 녹음과 받아쓰기, 음악, 캐릭터를 함께 사용하는 앱입니다. 앱 목록에는 **일정 위젯**으로 표시됩니다.

**현재 버전: Ver 0.1.3 · 최소 Android 8.0 · 64비트 ARM 기기 지원**
Ver 0.1.3에서는 홈 화면·다른 앱 위에 떠 있는 펫도 실제 그림 기준으로 이동하도록 고쳤습니다. 위쪽 투명 여백이 먼저 벽에 걸리던 문제를 수정하고, 투명한 부분에서 펫 조작이 시작되지 않도록 했습니다. 0.1.2의 앱 안 펫 히트박스·달력 개선과 기존 Flexcil 녹음 복원·PDF 연결 기능도 유지합니다.

Android 13 이상에서는 투명한 펫 여백·구멍의 터치를 뒤 앱으로 넘깁니다. 시스템의 가림 제한에 맞춰 펫 창이 약간 옅게 표시되고, 여러 펫이 겹치면 더 옅어집니다. Android 12 이하에서는 투명 부분에서 펫이 반응하지 않지만 뒤 앱으로 터치가 전달되지는 않습니다.

## 설치하고 시작하기

1. [Ver 0.1.3 배포 페이지](https://github.com/KIMY0UNGGON/ScheduleWidget-Moblie/releases/tag/v0.1.3)의 `Assets`에서 `ScheduleWidget-mobile-notes.apk`를 받습니다.
2. 기기에서 APK를 열고 Android가 요청하는 `이 출처 허용`을 켜서 설치합니다.
3. 앱을 열고 하단의 `달력 · 녹음 · 노트` 중 사용할 탭을 누릅니다. 탭이 없으면 설정에서 해당 기능을 켭니다.

처음 필기를 시작하려면 **노트 → 새 노트 → 새 노트**를 누르세요. 빈 노트 만들기는 약 1분입니다. 권한은 녹음·알림·캘린더·화면 위 캐릭터 등 필요한 기능을 사용할 때 허용하면 됩니다.

## 노트 쓰기

1. `노트 → 새 노트`를 누릅니다.
2. 빈 노트는 `새 노트`, 문서·사진·백업은 `파일 가져오기`를 고릅니다.
3. 편집기에서 펜으로 씁니다. 손가락으로 쓰려면 `⋮ → 손가락으로 필기`를 켭니다.
4. 파일로 남기려면 `⋮ → PDF로 저장` 또는 `PDF 공유`를 누릅니다.

필기는 자동 저장됩니다. 저장 실패 안내가 나오면 `다시 시도`로 저장을 마친 뒤 화면을 닫으세요.

PDF나 노트를 연 뒤 `⋮ → 노트 녹음`에서 연결된 녹음을 확인하고 재생할 수 있습니다. 여기서 시작한 녹음은 필기를 쓰지 않아도 그 노트에 연결되며, 기존 필기에 연결된 녹음도 함께 표시됩니다. 녹음의 `파일로 저장`은 M4A를 저장하고, `받아쓰기 보기 → ⋮ → 텍스트 파일로 저장`은 전사본 TXT를 저장합니다. 녹음 기능을 꺼도 기존 연결 자료는 볼 수 있습니다.

`.flex` 백업에 원본 녹음(`.fab`)이 있으면 재인코딩 없이 M4A로 복원해 원래 PDF·노트에 자동 연결합니다. 한 녹음에 여러 노트가 연결돼 있어도 각 노트에서 볼 수 있습니다. 필기별 재생 시각(`.rsync`)이 현재 필기와 정확히 일치하면 해당 시점도 복원합니다. 일치하지 않는 연결은 결과에 안내하며 추측해서 붙이지 않습니다. 원본 녹음이 없는 단독 `.flx` 파일에서는 오디오를 복원할 수 없습니다.

### .flex 백업 가져오기

1. `노트 → 새 노트 → 파일 가져오기`에서 `.flex` 파일을 고릅니다.
2. 복원이 끝나면 `폴더 열기`를 누릅니다.
3. **백업 파일 이름의 폴더 → 원래 하위 폴더 → 노트** 순서로 열어 PDF와 필기를 확인합니다.
4. `⋮ → 노트 녹음`에서 복원된 원본 녹음을 재생하거나 받아쓰기·M4A·전사본 TXT 내보내기를 사용합니다.

지원하는 필기는 편집·삭제할 수 있는 획으로 복원됩니다. 같은 백업을 다시 가져오면 `(2)`처럼 별도 폴더가 생깁니다. `.flx` 파일은 단독 노트로 가져옵니다.
백업을 취소해도 먼저 완료한 노트와 연결된 녹음은 보존합니다. 읽지 못한 녹음이나 문서는 결과에 안내하며 선택한 원본 백업은 변경하지 않습니다. 백업 입력은 최대 4GiB, 개별 원본 파일은 1GiB까지 처리합니다.

예전에 최상위 목록으로 가져온 노트는 출처를 추측해 자동으로 옮기지 않습니다. 백업별 폴더가 필요하면 원본 백업을 다시 가져오세요. 기존 노트는 그대로 남으므로 새로 복원한 내용을 확인한 뒤 정리하면 됩니다.

<details>
<summary>문서 가져오기·폴더 정리·백업 복원의 범위</summary>

- **파일과 폴더:** PDF·PPT·Word·사진을 여러 개 선택할 수 있습니다. `폴더 통째로 가져오기`는 하위 폴더의 PDF·PPTX·DOCX·.flex·.flx를 찾습니다. 일반 문서는 현재 노트 폴더에 들어가고, .flex 백업은 백업별 폴더를 만듭니다. 가져오는 중에는 취소할 수 있습니다.
- **목록 정리:** 폴더 경로를 눌러 이동하고 뒤로가기로 한 단계 올라갑니다. 제목 검색은 전체 노트에서 찾으며 이름·최근 수정순으로 정렬합니다. 노트의 이름 변경·폴더 이동·PDF 내보내기·삭제를 지원합니다. 폴더를 삭제하면 내용은 상위 폴더로 옮겨지고 노트는 남습니다.
- **다른 앱에서 열기:** PDF·PPT·Word·.flex·.flx를 다른 앱의 `열기` 또는 `공유`에서 일정 위젯으로 보내 가져올 수 있습니다. 설정에서 노트 기능이 켜져 있어야 합니다.
- **복원 범위:** 원래 페이지 순서, 여러 PDF 배경, 빈 페이지와 지원하는 필기를 복원합니다. 컨테이너에 원본 .flx가 있으면 해당 노트 안에도 보관합니다. 지원하지 않는 이미지·도형, 손상된 문서, 암호가 걸린 PDF는 결과 창에 안내합니다. 이미 PDF에 합쳐진 필기는 편집 가능한 획으로 분리할 수 없습니다.
- **문제 확인:** `진단 정보 공유`에는 파일 이름·크기·오류 종류가 들어갈 수 있습니다. 문서 본문·필기·토큰은 넣지 않으며, 공유 전에 내용을 확인할 수 있습니다. 손상된 필기 파일은 빈 필기로 덮어쓰지 않고 원본을 보존합니다.

</details>

- **도형 보정:** 일반 펜으로 직선·원·타원·곡선을 그린 뒤 **펜을 떼지 않고 끝에서 약 0.55초 멈춰 누르면** 모양을 정리합니다. 도구 막대의 `도형 보정 켬/끔`으로 바꿉니다. 작거나 모양이 불분명한 획은 유지합니다. 형광펜의 멈춰 누르기 직선 보정은 별도로 동작합니다.
- **페이지 편집:** `페이지`에서 이동·순서 변경·다중 선택을 합니다. 복제·회전·맨 앞/뒤 이동·다른 노트로 복사·새 노트로 추출·일부 페이지 PDF 내보내기·배경 변경·필기 지우기·삭제를 지원합니다. 실행 취소·다시 실행은 최대 200단계이며 페이지 삭제도 되돌릴 수 있습니다.
- **페이지 추가:** 무지·줄·모눈·점·코넬·오선지와 종이 크기·색을 고릅니다. PDF·사진·카메라·다른 노트·PPT·Word에서 페이지를 넣을 수도 있습니다. 마지막 페이지 아래로 충분히 당겼다가 놓으면 빈 페이지가 추가됩니다. PDF 배경은 속지로 바꿀 수 없고 마지막 한 페이지는 삭제할 수 없습니다.
- **입력과 녹음:** 손가락 필기가 꺼져 있으면 손가락은 넘기기·확대에 씁니다. 지원 기기의 펜 측면 버튼은 임시 지우개와 펜/지우개 전환에 사용합니다. 편집기에서 녹음을 시작하고 `녹음 연동`을 켜면 필기를 눌러 당시 녹음을 재생합니다. 전체 화면도 지원합니다.

</details>

### PPT·Word 변환 방식

설정 → `노트 → PPT·Word 변환 방식`에서 선택합니다.

| 방식 | 동작 |
| --- | --- |
| 폰에서 | PPTX·DOCX를 기기에서 PDF로 변환합니다. 인터넷이 필요 없으며 글자·그림·표의 배치가 원본과 다를 수 있습니다. |
| 구글 드라이브 | 별도 문서 업로드 동의 후 선택한 계정의 Drive에서 변환합니다. 인터넷·구글 권한이 필요합니다. |
| 자동 | 문서 업로드 동의와 Drive 권한이 있으면 Drive를 쓰고, 그렇지 않으면 기기에서 변환합니다. |

예전 형식인 `.ppt/.doc`은 Drive 변환만 지원합니다. Drive 변환 뒤 임시 사본 삭제를 시도하지만 오류가 나면 남을 수 있습니다. 앱 안내와 자신의 Drive를 확인하세요. 문서 업로드 허용은 설정 → `개인정보`에서 끌 수 있습니다.

## 일정 넣기

1. `달력`에서 날짜를 누르고 일정을 추가합니다.
2. 제목을 적고 필요한 시간·색·메모·중요 표시를 고릅니다.
3. 여러 날은 `연속 날짜`, 정기 일정은 `매일·매주·매월·매년`을 고릅니다.

달력 위 기간 표시를 누르면 월간·주간·사용자 설정 보기로 바꿀 수 있습니다. 마감 알림은 설정 → `마감 알림`에서 켭니다.

<details>
<summary>달력·할 일·반복 일정·알림 상세</summary>

- **보기:** 월간은 월요일부터 시작하는 6주 격자, 주간은 월~일을 세로로 표시합니다. 사용자 설정은 선택한 날짜부터 1~14일을 가로로 표시합니다. 한국 공휴일·대체공휴일과 테마, 글자 크기·넘김 효과 설정을 지원합니다.
- **할 일:** 추가·수정·삭제·완료, 중요 표시와 메모를 지원합니다. 달력·위젯·캐릭터 달력에 D-day가 표시되며 설정에서 끌 수 있습니다. 중요 일정은 날짜 안에서 먼저 표시됩니다. 설정의 `할 일 목록`에서도 관리합니다.
- **기간과 반복:** 연속 날짜는 일정 하나를 기간 전체에 표시하며 완료·삭제도 전체 기간에 적용합니다. 매일·매주·매월·매년 반복은 종료일까지 개별 일정을 만듭니다. 반복 일정은 변경·삭제할 적용 범위를 선택합니다.
- **다음 일정:** `다음 일정`을 누르거나 오른쪽 화살표를 길게 눌러 다음 기간의 미완료 일정을 확인합니다.
- **마감 알림:** 당일~30일 전과 알림 시각을 고릅니다. 시간이 지정된 일정은 일정 시각에 알립니다. 알림 권한·정확한 알람 허용이 필요하며 `테스트 알림`으로 확인할 수 있습니다.

</details>

### 구글·기기 캘린더 연동

설정 → `구글/기기 캘린더 연동`에서 원하는 기능만 켭니다.

| 연동 | 사용하는 데이터 |
| --- | --- |
| 구글 캘린더 | 선택한 계정의 기본 캘린더와 앱 일정을 양방향으로 맞춥니다. PC 앱과 함께 쓸 때는 같은 계정을 선택합니다. |
| 기기 캘린더 | 휴대폰에 동기화된 구글·삼성·기본 캘린더 일정을 읽어 표시합니다. 별도 로그인 대신 Android 캘린더 권한을 사용합니다. |

## 수업 녹음하기

1. 설정 → `수업 녹음`에서 기능을 켜고 마이크 권한을 허용합니다.
2. 캐릭터를 **세 번** 누르거나 노트 편집기의 녹음 버튼으로 시작합니다.
3. 녹음 중 캐릭터를 **두 번** 누르거나 알림의 `정지`로 멈춥니다.
4. `녹음` 탭에서 녹음을 재생하거나 `받아쓰기`를 누릅니다.

받아쓰기를 처음 사용하려면 설정에서 모델을 내려받으세요. 기본 모델 `SenseVoice`는 약 228MB입니다. **녹음 내용은 받아쓰기를 위해 서버에 보내지 않고 기기에서 처리합니다.**

<details>
<summary>음질·받아쓰기 모델·전사본 편집</summary>

- **녹음 설정:** 표준·고음질·최고 음질, 기본·원거리·처리 최소 마이크를 고릅니다. 입력 음량(50~400%)과 앱 재생 음량은 따로 조절합니다. 화면을 꺼도 녹음하며 저장 공간 부족 시 멈추고 그때까지 저장합니다. 너무 짧은 녹음은 저장하지 않습니다.
- **녹음 관리:** 이름 변경·재생·공유·삭제와 받아쓰기·다시 받아쓰기를 지원합니다. 재생 중 증폭과 자막 크기를 바꿀 수 있습니다.
- **모델 선택:** SenseVoice 약 228MB, Whisper small 약 357MB, Qwen3-ASR 0.6B 약 941MB, Whisper turbo 약 988MB를 선택합니다. 모델별 속도·결과와 필요한 메모리는 기기에 따라 다릅니다. 모델은 외부 배포 서버에서 내려받으며 저장 공간을 확인하고 삭제할 수 있습니다.
- **자동 처리:** 자동 받아쓰기를 켜면 녹음 종료 후 받아씁니다. 화자 분리는 별도 모델이 필요하며 화자 수를 자동 또는 직접 지정합니다.
- **전사본 편집:** 문단·화자 이름·문단의 화자를 고치고 찾아 바꾸기·되돌리기를 사용합니다. 자동 고치기 단어는 다음 받아쓰기에도 적용할 수 있습니다. 재생 위치를 따라가며 읽고 복사·공유·.txt 저장으로 내보냅니다. .srt/.vtt 자막 파일 내보내기는 지원하지 않습니다.

</details>

## 음악 듣기

1. 설정 → `플레이리스트`에서 새 목록을 만듭니다.
2. `파일 추가`·`폴더 추가`·`YouTube·Spotify 링크`로 곡을 넣습니다.
3. 곡을 눌러 재생합니다.

기기 음악과 링크를 같은 목록에 담고 순차·랜덤·한 곡 반복으로 재생합니다. 음악 막대의 `재생 소스`에서 제어할 음악 앱을 고를 수 있습니다.

<details>
<summary>YouTube 목록·곡 끼워 넣기·외부 음악 앱</summary>

- **곡 끼워 넣기:** 곡을 길게 눌러 그 아래를 삽입 위치로 정합니다. 이후 파일·폴더·링크·재생목록은 그 자리에 들어가고 `맨 뒤에 추가`로 되돌립니다.
- **링크와 공유:** YouTube·YouTube Music 링크를 받습니다. 해당 앱의 `공유 → 일정 위젯`으로 원하는 플레이리스트에 추가할 수도 있습니다.
- **YouTube 재생목록:** `YouTube 재생목록`에서 로그인한 계정의 재생목록·비공개 목록·좋아요 목록을 가져옵니다. 구글 프로젝트와 계정 설정이 필요하며 공개 배포용 로그인 방식은 추가 확인이 필요합니다.
- **재생 중 목록:** YouTube·YouTube Music의 현재 대기열을 `지금 재생 목록`으로 가져옵니다. 다시 가져오면 덮어쓰며 YouTube Music 곡은 제목·아티스트로 검색합니다. 알림 접근 권한이 필요합니다.

## 캐릭터와 위젯

캐릭터는 설정 → `캐릭터 설정 → 캐릭터 표시`에서 켭니다. 기본은 흰 모찌입니다. 홈 화면 위젯은 홈 화면의 빈 곳을 길게 누른 뒤 `위젯 → 일정 위젯`에서 추가합니다.

| --- | --- |
| 앱 안 캐릭터 | 한 번 눌러 앱·음악·달력·설정·노트 바로가기와 녹음 메뉴 열기 |
| 화면 위 캐릭터 | 다른 앱 위에 표시, 드래그 이동, 두 번 눌러 이동·크기 조절 가능한 7일 달력 열기 |
| 음악 막대 위젯 | 현재 곡과 이전·재생/일시정지·다음 버튼 |
| 플레이리스트 위젯 | 목록 전환과 곡 선택·재생 |

### 홈 화면 달력 위젯

| 위젯 이름 | 표시 범위 |
| --- | --- |
| 7일 달력 | 오늘부터 7일을 한 줄에 표시합니다. |

7일·30일 달력은 앱의 기간 설정과 별개로 표시합니다. `‹ ›`로 각각 7일·30일씩 이동하고 `오늘`로 현재 기간에 돌아옵니다. 날짜 또는 `+`를 누르면 일정을 추가합니다. 일정이 적게 보이면 위젯 높이를 늘리세요.

<details>
<summary>캐릭터 설정·가져오기·화면 위 조작</summary>

- **말풍선 메뉴:** 앱 바로가기를 최대 3개 설정합니다. 녹음 기능이 켜져 있으면 옆으로 넘겨 녹음·음질·마이크·모델·최근 받아쓰기를 봅니다. 녹음 기능이 꺼져 있으면 세 번 누르기로 MP3 도구를 엽니다. 순천향톡이 설치되어 있으면 모바일 신분증 바로가기를 설정할 수 있고 자동 화면 이동에는 접근성 권한이 필요합니다.

- **7일 달력과 음악:** 녹음 중이 아닐 때 화면 위 캐릭터를 두 번 누르면 오늘부터 7일을 가로로 봅니다. 상단 날짜 범위를 끌어 패널을 옮기고 가장자리·모서리를 끌어 크기를 바꿉니다. 7개 날짜 칸과 글자 크기가 패널 크기에 맞춰 조절되며 설정한 크기를 기억합니다. `설정`은 앱 전체 설정을 열고 날짜·`+ 일정`은 일정을 추가합니다. 말풍선의 음악은 미니 플레이어와 플레이리스트로 펼칠 수 있으며 앱 미니 달력은 말풍선 스위치로 숨길 수 있습니다.

## PC 데이터 옮기기

1. 설정 → `PC에서 가져오기`에서 PC 앱의 `schedules.json`을 고릅니다.
2. 가져온 일정·플레이리스트를 확인합니다. PC 경로의 음악은 곡의 `재연결`로 기기 파일을 지정합니다.
3. 구글 캘린더를 다시 연결하려면 가져온 내용을 확인한 뒤 연동을 켭니다.

**가져오면 현재 일정·플레이리스트가 파일 내용으로 바뀌고 구글 자동 동기화는 해제됩니다.** 기존 구글 일정은 파일 가져오기만으로 삭제하지 않습니다. PC의 캐릭터 선택·표시 설정도 이어 쓸 수 있으며 사용자 캐릭터 파일은 기기에도 가져와야 합니다.

설정 → `내보내기`로 PC 앱에서 사용할 `schedules.json`을 저장합니다. 노트·녹음 전체를 담는 백업 파일은 아니므로 노트는 PDF, 녹음·전사본은 각 화면의 공유·저장 기능을 사용하세요.

## 앱 업데이트

설정 → `앱 업데이트 → 업데이트 확인`에서 직접 확인합니다. **게시된 정식 릴리스만 대상이며 초안·사전 릴리스는 제외합니다.** 현재 배포 버전은 Ver 0.1.3입니다.

이전 버전에서 업데이트 확인을 누르면 Ver 0.1.3을 받을 수 있습니다. Ver 0.1.3의 내부 버전 코드는 8이며 기존 배포본과 같은 서명을 유지합니다. 기존 앱을 삭제하지 않고 덮어 설치할 수 있습니다.

새 버전이 제공되면 `다운로드 후 설치`를 누르고 설정 화면에 머무릅니다. 다운로드 후 Android 설치 화면에서 확인합니다. 설정 화면을 나가면 다운로드가 취소됩니다.

업데이트 확인에는 GitHub 토큰이 필요하지 않습니다. 설치본과 서명이 다르면 같은 서명의 APK를 관리자에게 요청하세요.
