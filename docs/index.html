ScheduleWidget Notes

일정과 필기를 함께 관리하는 Android 앱입니다. PDF·PPT·Word·사진을 노트로 가져오고, S펜이나 스타일러스로 필기합니다. .flex/.flx 노트 백업에서 노트와 지원하는 필기를 복원합니다.

앱에서 할 수 있는 일

  • 노트 필기, 페이지 추가·정리, PDF 내보내기
  • 달력과 할 일, 선택적인 구글·기기 캘린더 연동
  • 캐릭터 표시와 선택적인 Drive 동기화
  • 수업 녹음, 기기 내 음성 인식, 음악 재생목록 관리
  • 설정에서 GitHub 정식 릴리즈 확인·다운로드·설치

구글 연동은 선택 사항입니다

구글 캘린더는 기본 캘린더와 일정을 맞추고, Drive는 캐릭터 동기화와 별도 동의한 문서 변환에 사용합니다. YouTube 로그인은 계정의 재생목록을 가져오는 데 사용합니다. 노트와 기기 내 문서 변환은 구글 로그인 없이 이용할 수 있습니다.
