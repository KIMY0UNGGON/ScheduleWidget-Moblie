# Android 노트 재검수

검수 범위는 `ScheduleWidget-mobile-notes`입니다. 일반 모바일판과 Windows 소스는 수정 대상에서 제외했습니다. Sonnet 5.5 1개와 Opus 5.5 2개가 읽기 전용 독립 검수를 했고, GPT-6 Luna Max 4개가 저장소·편집기·가져오기·구글 연동 수정을 분담했습니다. 독립 보고서의 제안은 코드 경로를 확인한 뒤 반영했습니다.

## 수정한 결함

| 영역 | 수정 |
| --- | --- |
| 저장·삭제 | 메타 ID와 실제 노트 폴더 일치 확인, 노트·필기·PDF 경로 우회 차단. 삭제 후 늦은 저장이 노트를 되살리지 않는 기존 차단 유지 |
| PDF 삽입 | 잘못된 PDF를 검증한 뒤에만 소스로 저장 |
| PDF 내보내기 | 대기 중 저장 완료 후 읽기, 원본·페이지 인덱스 사전 검사, 캐시에서 완성한 뒤 대상 파일 열기 |
| 폴더 | 이름 변경·삭제의 디스크 처리를 IO에서 수행하고 최신 노트 목록 사용 |
| 외부 공유 | `content://`만 수용하고 앱 자체 FileProvider URI 재사용 거부 |
| Flexcil | 문서별 오류를 구분해 정상 문서 복원 계속, 암호 PDF·지원하지 않는 이미지 객체 안내, 빈 페이지 목록의 PDF 폴백 |
| 가져오기 취소 | 이미 저장한 노트 수를 보고하고 큰 ZIP 읽기·복사 중 취소 확인. 보고서에 예외 메시지의 원문 조각을 넣지 않음 |
| 필기 | 손가락 필기 중 펜 우선 입력, 손가락 이벤트가 펜 버튼 해제로 해석되지 않도록 보강, 기기가 전달한 펜 키의 Activity 처리와 모달 전환 시 임시 상태 정리 |
| 페이지 당김 | 자동저장 중에도 한 페이지 추가, 스프링과 입력 좌표 충돌 방지, 다중 터치 오프셋 충돌 방지 |
| 실행 취소 | 페이지 인덱스를 바꾸기 전에 진행 중 필기·올가미 취소 |
| 지우개 | 굵은 획 가장자리에 닿는 부분 지우기의 선 굵기 반영 |
| 화면 이탈 | 기존 저장 성공 후 이동 유지, 외부 intent도 저장 관문 적용, dispose 저장 실패 안내 |
| 문서 변환 | 폰에서 변환 설정 준수, 편집기 네트워크를 IO에서 수행, Drive 권한과 별개인 업로드 동의, 표시된 임시 사본 재정리 |
| 캘린더 | 기본 캘린더 ID 조회에 필요한 범위 추가, 계정 확인 실패 시 중단, PC JSON 가져오기 시 자동 동기화 해제·연결 정보 초기화, 늦은 동기화 커밋 차단 |
| Drive | 계정 변경 시 이전 삭제 표식 분리, 인증 오류 표시, 연결 해제와 Google 권한 취소 차이 안내 |
| 개인정보 | 앱 안 정책·동의 철회, 토큰·문서 업로드 동의를 클라우드/기기 이전 백업에서 제외, 요청 전 YouTube WebView 생성 방지 |

## 기능별 분리

기존 공개 진입점과 노트 파일 형식은 유지합니다. `NoteStore`는 생성·페이지 전송·내보내기·썸네일 모듈을 조합하고, 가져오기는 파일 읽기·SAF 트리·Office 변환과 Flexcil 아카이브 읽기를 분리했습니다. 편집기는 캔버스와 페이지 다이얼로그를 분리하고, 설정은 화면과 컨트롤, 구글 OAuth 카드와 기기 캘린더 카드를 나눴습니다. 문서 업로드 동의와 정책 화면은 `privacy/`가 담당합니다.

## 검증과 제한

단위 테스트, lint, debug 앱·계측 APK 빌드와 Android API 35의 기존·추가 회귀 검사를 실행합니다. 복원 검증용 개인 `.flex` 원본은 저장소·APK에 포함하지 않습니다. 계측은 저장 실패, 늦은 저장, 메타 ID 불일치, 경로 우회, 잘못된 PDF, 내보내기 취소·대상 보존, 안전하지 않은 URI, 필기·당김·실행 취소, 문서 동의·취소·백업 제외를 확인합니다.

실제 구글 계정의 인증·API 권한은 로그인된 Cloud Console과 기기 계정이 필요합니다. 코드 검사나 네트워크 없는 회귀 검사만으로 OAuth 등록 완료를 판정하지 않습니다. 현재는 비공개 테스트 단계이며 공개 정책 사이트 배포·저장소 공개 전환·Google 프로덕션 검증 제출은 하지 않습니다.

펜 버튼은 표준 MotionEvent와 삼성 접촉 이벤트를 검사합니다. AOSP Android 15는 예약된 stylus 키를 시스템에서 소비하므로 `adb shell input keyevent 308`을 실제 펜 입력 검증으로 사용하지 않습니다. 추가 UI 계측은 공개 Activity 이벤트 경로에 이벤트를 전달하여 실제 도구 표시의 펜/지우개 전환과 모달 전환 뒤 임시 지우개 해제를 확인합니다. 실제 태블릿의 버튼 전달 방식은 기기에 따라 달라질 수 있습니다. [Android 15 시스템 처리](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android15-release/services/core/java/com/android/server/policy/PhoneWindowManager.java)

손상된 필기 파일을 빈 데이터로 덮어쓰지 않습니다. 저장 자체가 실패한 상태에서 Activity가 재생성되면 로컬 디스크에 반영하지 못한 내용이 남지 않을 수 있어 실패를 안내합니다. Flexcil의 지원하지 않는 객체는 결과에 표시하고, 제공된 원본 `.flx`가 있으면 보관합니다. 이전 버전에서 Drive에 남긴 표식 없는 변환 사본은 사용자가 직접 확인해야 합니다. YouTube의 기존 Desktop OAuth 클라이언트 재사용은 공개 배포 전에 별도로 확인할 항목입니다.

실행 결과: 단위 테스트 151개(실패·오류·건너뛰기 0), lint 오류 0·경고 88, API 35 계측 10개 모두 통과했습니다. 앱 안 정책 화면의 문서 업로드 선택·정책 본문·지원 이메일도 확인했습니다. [최종 검증 기록](VALIDATION.json)에 APK 해시와 수치를 보관합니다.
